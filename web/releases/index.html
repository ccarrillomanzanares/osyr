Early test build. Installing to disk erases the whole disk you choose, including any other operating system on it.

1 · Check the download

sha256sum osyr.img.xz      # Linux; on macOS: shasum -a 256 osyr.img.xz
certutil -hashfile osyr.img.xz SHA256      # Windows

It must match the sha256 above (also in osyr.img.xz.sha256).

The image is also described by a signed manifest, osyr.img.xz.manifest + .sig, signed with the OSYR release key (update-signers). An installed OSYR checks it before updating; you can too: ssh-keygen -Y verify -f update-signers -I osyr-release@ccmai.org -n osyr-image -s osyr.img.xz.manifest.sig < osyr.img.xz.manifest.

2 · Write it to a USB stick (16 GB or more)

  1. Windows, macOS or Linux: balenaEtcher or Rufus (Windows; DD mode) can write the .img.xz directly.
  2. Linux, from a terminal (replace sdX with your USB stick; everything on it is erased): 
    xzcat osyr.img.xz | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync

3 · Start from the USB

  1. Turn the laptop on and open its boot menu (usually F9 on HP, F12 on Dell and Lenovo, Esc or F8 on others). Choose the USB stick.
  2. First start: language, keyboard, time zone, your password and wifi. The user is osyr.
  3. The AI model loads in the background: the first answer can take a minute or two.

4 · Install on the disk (optional)

  1. From OSYR running on the USB, open a terminal (Super+Enter) and run sudo osyr-install.
  2. Choose the disk, check what will be erased, and type the disk name to confirm.
  3. Choose a passphrase: your files are encrypted with it and it is asked at every start. If you forget it, they cannot be recovered.
  4. When it finishes, turn the laptop off, remove the USB and turn it on.

Or run it in VirtualBox

  1. Check the download: sha256sum osyr.ova (or shasum -a 256, certutil -hashfile ... SHA256) must match the sha256 above (also in osyr.ova.sha256).
  2. In VirtualBox: File → Import Appliance, choose osyr.ova and import. It comes with 8 GB of RAM and 4 CPUs, the minimum for the local AI.
  3. Leave the firmware as BIOS: do not turn on EFI in the VM settings.
  4. Start it. The first start is the same as on a USB stick: language, keyboard, time zone, your password and wifi (in the VM the network already works). The user is osyr.
  5. Installing to disk (step 4) is not needed in the VM.

If it is very slow: turn on virtualization (VT-x or AMD-V) in your computer's BIOS, and on Windows turn off Hyper-V, which slows VirtualBox down. Without AVX2 in the processor the local AI is very slow: use a server model.

Updates

OSYR checks once a day for a new version signed by the OSYR team and shows a notice; it never installs anything by itself. To install, open a terminal and run sudo osyr update code apply: it shows what will change, asks first, and sudo osyr update code rollback undoes it. Changes that need a new image (new programs, the kernel) are published here. More in the help page.

Privacy

The AI runs on the laptop. Nothing leaves it unless you connect a remote AI provider (the assistant tells you) or send a diagnostic report with osyr-diag. The report carries logs, hardware details, network names and a hardware test; not your conversations unless you ask for it with /report chats, and never AI keys, wifi passwords or the text of your reminders. It asks before adding your last screenshots.

Problems?

Locked screen, keyboard shortcuts and commands: see the help page (in OSYR, Super+F1). Run osyr-diag on the laptop: it sends logs and a hardware self-test (your conversations only if you ask for it) so we can see what happened. Or write to contact@ccmai.org.
