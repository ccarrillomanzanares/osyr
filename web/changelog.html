changelog

v0.30.1 — 2026-11-04

source · code update: type /update in the chat

fixes

  • After connecting a remote AI provider with /pair, the first answer no longer waits for the computer's own model to finish loading (minutes on older laptops).
  • The daily update check works on a freshly installed system.
  • Emoji show in colour instead of small boxes. This needs the next system image: the new font is not part of a code update.

privacy

  • A problem report (/report) now shows your latest conversations with the assistant and asks before including them; by default they are left out.

v0.30.0 — 2026-11-04

download · source · new install from the image

OSYR is the new name of the system previously called AIOS, a name already used by many other projects. The version numbers continue. Releases are now signed with a new key, so a computer with AIOS installed cannot update to OSYR: write the new image to a USB stick and install it again (first ask the assistant to make a backup of your files to a USB disk).

First release of OSYR: a small Linux system for 8 GB laptops with an AI assistant that runs on the computer itself. Chat and voice, a browser the assistant can read and use, files, reminders, questions about what is on the screen, Bluetooth, sound, USB disks, installation to disk with optional encryption, signed updates of code and of the whole system with a way back.

security

  • Wi-Fi passwords, AI provider keys and the problem-report token never appear in the list of running programs: they are passed privately instead of on the command line.
  • When a saved Wi-Fi password has changed, the assistant asks for the new one without showing it on screen.
  • Every release and system image is signed with the OSYR release key; the downloads page links the signed manifest and explains how to check it.
  • The background update check runs with the least access it needs.

fixes

  • A stopped chat or voice process is no longer confused with an unrelated program that got the same process number.
  • Going back to the previous system version works from the emergency console too.
  • Listing disks no longer fails when a USB stick was removed without ejecting it, and USB disks with odd names are mounted in the right place.
  • Problem reports no longer miss an error while packing, and screenshots with spaces in their names are included.
  • Downloaded models are checked against their published checksums.
