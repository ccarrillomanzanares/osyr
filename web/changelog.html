v0.33.0 — 2026-11-24

download · system update: osyr update image, or a new install from the image

new

  • Where should the assistant's model run on this computer? osyr ai advise (/ai advise in the chat) measures the model's speed here, says how long a simple request takes and shows the choices, one of them recommended: the model on this computer, a large model on this computer, or a model on another machine. The first start ends with it. It changes nothing by itself.
  • A large model on this computer: osyr ai local get large (/model in the chat) downloads the Qwen3.6-35B (23 GB, for computers with 32 GB of memory) into your home partition, where it survives system updates. It asks first, resumes a cut download and checks the files. osyr ai local use large switches to it and use small goes back.
  • The model on a graphics card: osyr ai gpu on (/gpu in the chat) tries an AMD or Intel card through Vulkan and keeps it only if it is faster than the processor; if the model does not start there, it goes back by itself. Off unless you ask. NVIDIA cards are not supported. Not yet tried on a real card: please report what you see with /report.
  • A second model for hard tasks: when there is a provider on another machine, the assistant on this computer can hand a task it cannot do to it. With a single provider, that one is the second model; with several, choose it with osyr ai second. The assistant asks before the conversation leaves this computer, and osyr ai second off turns this off.
  • A picture of the screen on request: osyr ui screenshot saves one in Pictures/Screenshots.
  • zip and xz are in the system, and tar packs and unpacks compressed archives (tar -czf).
  • osyr sys power also shows the battery charge.

fixes

  • Ejecting a USB disk (osyr disk eject) and suspending when the battery is almost empty asked for a password and failed without one, unless a password had been typed a moment before. They no longer ask for one.
  • osyr bt connect and osyr net wifi connect take a name of several words without quotes.
  • Passwords can be changed again. In v0.32.0 no password could be changed, and the first start could not replace the default one: if you installed v0.32.0, change your password after updating (passwd).
  • Computers installed before 12 November are offered new system versions again. Type /update first (code), then update the system.
  • Realtek RTL8723BE wifi: its power saving is turned off, because waking the card could freeze the whole computer.
  • A spoken sentence that gets stuck is cut instead of repeating for ever, and /speak off also silences what is being said.
  • Asked which model it is, the assistant gives the name of the model loaded, not "local"; and the commands it tells you to type carry osyr in front.
  • The assistant looks at the screen once per request, instead of repeating a slow look.
  • The count of times the processor slowed down from heat was too high (each core was counted once per thread).
  • The hardware test checks vision through a remote provider too, and ends when run without a terminal.

v0.32.0 — 2026-11-13

download · system update: osyr update image, or a new install from the image

new

  • The assistant can run commands in a shell for what the osyr commands do not cover. What only reads runs without asking; what changes something shows the command and asks (yes, always or no); what is destructive is blocked. A heavy command comes with a plain line saying what it does, and sudo asks for your password as usual.
  • Install programs: osyr box install <program>, or ask the assistant. They go into a Debian container (the box) that sees your home folder but not your keys or the assistant's settings; the system itself is not touched. osyr box search, list, remove, update and reset. First version: it needs the Internet and free disk space, and programs that only speak X11 have no window yet.
  • Open and close applications: osyr app list, osyr app run <name> [file] and osyr app stop <name>, for the system's applications and the box's.
  • Find a file by saying what it is called, and read it by its bare name.

changes

  • The assistant takes up to 12 steps per request, stops when a call repeats with the same result, and takes a "no" as final for that request.

  • Nothing changes in the system: this version only renews the source repository, which starts again from a single commit. Earlier versions remain downloadable.

v0.31.0 — 2026-11-11

download · system update: osyr update image, or a new install from the image

new

  • Choose the assistant's voice: ask "use another voice" or run osyr audio voice speaker 2. Spanish has two speakers, English many; it says a sample so you can hear it. osyr audio voice shows which one is in use.
  • Faster listening on slow computers: osyr audio voice listen fast understands what you say about twice as fast but makes more mistakes. It downloads 60 MB once, and an interrupted download resumes where it stopped. osyr audio voice listen accurate goes back.
  • Emoji in colour, now included in the system image.

fixes

  • When you speak to the assistant in another language, changing the voice applies to that language's voice.
  • A damaged voice settings file no longer stops spoken answers, reminders or battery warnings.
  • Includes the fixes of v0.30.1.

v0.30.1 — 2026-11-04

source · code update: type /update in the chat

fixes

  • After connecting a remote AI provider with /pair, the first answer no longer waits for the computer's own model to finish loading (minutes on older laptops).
  • The daily update check works on a freshly installed system.
  • Emoji show in colour instead of small boxes. This needs the next system image: the new font is not part of a code update.

privacy

  • A problem report (/report) now shows your latest conversations with the assistant and asks before including them; by default they are left out.

v0.30.0 — 2026-11-04

download · new install from the image

OSYR is the new name of the system previously called AIOS, a name already used by many other projects. The version numbers continue. Releases are now signed with a new key, so a computer with AIOS installed cannot update to OSYR: write the new image to a USB stick and install it again (first ask the assistant to make a backup of your files to a USB disk).

First release of OSYR: a small Linux system for 8 GB laptops with an AI assistant that runs on the computer itself. Chat and voice, a browser the assistant can read and use, files, reminders, questions about what is on the screen, Bluetooth, sound, USB disks, installation to disk with optional encryption, signed updates of code and of the whole system with a way back.

security

  • Wi-Fi passwords, AI provider keys and the problem-report token never appear in the list of running programs: they are passed privately instead of on the command line.
  • When a saved Wi-Fi password has changed, the assistant asks for the new one without showing it on screen.
  • Every release and system image is signed with the OSYR release key; the downloads page links the signed manifest and explains how to check it.
  • The background update check runs with the least access it needs.

fixes

  • A stopped chat or voice process is no longer confused with an unrelated program that got the same process number.
  • Going back to the previous system version works from the emergency console too.
  • Listing disks no longer fails when a USB stick was removed without ejecting it, and USB disks with odd names are mounted in the right place.
  • Problem reports no longer miss an error while packing, and screenshots with spaces in their names are included.
  • Downloaded models are checked against their published checksums.
